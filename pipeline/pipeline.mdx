**Pipeline** is a kanban board for your sales or follow-up process. Each board is a pipeline. Each column is a stage. Each card is a contact.

This page does **not** create contacts. Contacts come from PowerLists, imports, conversations, and the rest of the workspace. Pipeline only **places** those contacts into stages.

## ✨ What you can do

- See where every lead sits in your process
- Drag a contact from one stage to the next
- Create, rename, reorder, or delete pipelines and stages
- Open a contact for details, notes, appointments, and messages
- Optional: sync the board with a connected **LeadConnector** (GHL) location

**🔗 How the pieces fit together**

**Pipeline → Stages → Contacts**

| Piece | What it is | Example |
|-------|------------|---------|
| **Pipeline** | The whole board | Sales Funnel |
| **Stage** | One column on that board | New Lead, Contacted, Closed |
| **Contact card** | A person currently in that stage | Sara, +1… |

If LeadConnector is connected:

**LeadConnector location → pipelines → stages → deals**

- Each location has its **own** pipelines
- Choosing a location on a pipeline creates that board on that location too
- A **deal** is that contact sitting on a LeadConnector stage
- Or keep a pipeline local with **Don’t sync to GHL**

## 📍 Location filter

Appears when LeadConnector locations are connected. Filters **which pipelines** you see — it does not move contacts.

| Option | What you see |
|--------|----------------|
| **All** (default) | Every pipeline, synced or not |
| **Don’t sync** | Only pipelines **not** linked to LeadConnector |
| **A location name** | Only pipelines linked to that location |

Empty states may say **No pipelines synced**, **No unsynced pipelines**, or **No pipelines** — switch the filter or open **Manage**.

## 🗂️ The board

Pick a pipeline from the **Pipeline** dropdown. Columns appear left to right in stage order.

Each column shows:

- Stage name + pencil (rename)
- **Dial** — opens the Dialer for contacts in that stage
- Contact count
- Cards (scroll to load more)

Empty columns say **No contacts in this stage**.

### 🧑‍💼 Contact cards

Each card shows name, phone, email, **Call**, and **Message** (opens [Conversations](/conversation/conversations)).

- Click the **card** (not Message) to open **Contact Details**
- **Drag** a card to another column to change stage — **Contact moved** confirms it

<Tip>
Contacts appear only after they are **assigned to a stage**. Being in a PowerList is not enough by itself.
</Tip>

## ➕ Create a pipeline

<img
  src="/images/pipeline/add-pipeline.png"
  alt="Add Pipeline form with name, GHL Location, Powerlists, and stages"
  className="rounded-lg border shadow-sm"
/>

1. Click **Manage** → **Add Pipeline**
2. Enter a **Pipeline Name** (required)
3. **GHL Location** (if LeadConnector is connected):
   - **Don’t sync to GHL** — workspace only
   - A location — board and stages are created there when you save
4. **Powerlists** (optional) — search and select one or more lists
5. **Pipeline Stages** — defaults: New Lead, Contacted, Proposal Sent, Closed
6. **Add Stage** for more columns; drag to reorder
7. Click **Save Pipeline**

You need at least one stage, and every stage needs a name.

---

## ✏️ Edit a pipeline

1. **Manage** → pencil on that row (**Edit Pipeline**)
2. Change name, PowerLists, or stages
3. **Save Pipeline**

**🔒 GHL Location when editing**

- Not linked yet → you can pick a location or leave **Don’t sync to GHL**
- Already linked → location is locked (*cannot be changed*)

Saving a linked pipeline also updates that board in LeadConnector.

**Stages in the form**

- **Add Stage** → then **Save Pipeline**
- Rename in the stage box
- Drag to reorder
- Trash a stage (you cannot remove the last one) → **Save Pipeline** or it is not removed

**✏️ Rename a stage from the board**

1. Click the pencil on the column header
2. Type the new name → Enter or click away (Escape cancels)
3. **Stage name updated** confirms it

On a linked pipeline, the name updates in LeadConnector too.

---

## 🗑️ Delete a pipeline

1. **Manage** → trash icon
2. Confirm **Are you sure you want to delete this pipeline?**

<Warning>
If the pipeline is linked to LeadConnector, that board is deleted there too — including deals on it. Unlinked pipelines (**Don’t sync to GHL**) are removed from this workspace only.
</Warning>

## 📌 Put a contact on a pipeline

**From Conversations**

1. Open the contact → **Pipelines** section
2. Choose **Pipeline** and **Pipeline Stage** → save

**From the board**

Drag a card between stages (move, not first placement).

**From a workflow**

Use **Pipeline stage changed** as a trigger, or set pipeline/stage as an action in the [workflow builder](/workflow/all-workflows).

## 🔄 LeadConnector (GHL) sync

Connect locations first; sync second.

**🔌 Connect a location**

1. **Settings → Integration → LeadConnector**
2. **Connect New** (or **Re-Connect** if expired)
3. Finish login and pick the location

Each location has its own pipelines. Actions include **Sync Pipeline**, **Re-Connect**, and **Disconnect**.

**🔄 Sync Pipeline (LeadConnector → this workspace)**

Use when boards already exist in LeadConnector.

1. **Settings → Integration → LeadConnector**
2. On that location’s row, click **Sync Pipeline**
3. Wait for sync to finish

| Result | Meaning |
|--------|---------|
| **New** | Board did not exist here — created with stages |
| **Linked** | Matching board was already here — connected, not duplicated |
| **Stages** | Stages created or matched |

Sync is **per location**. Syncing Location A does not import Location B.

**➡️ Create or edit here (this workspace → LeadConnector)**

No Sync click needed — **saving** is enough.

| You do this | What happens in LeadConnector |
|-------------|-------------------------------|
| Create pipeline + choose location | Board and stages created there |
| Edit linked pipeline | Linked board updated |
| Rename stage from board | Stage name updated |
| Delete linked pipeline | Board deleted there too |
| **Don’t sync to GHL** | Nothing created in LeadConnector |

**💼 Deals when a contact changes stage**

When you move a contact (board or Conversations):

- **Contact linked to LeadConnector** → deal created or moved to the matching stage
- **Contact not linked** → they still move on **your** board; no deal over there

Sync alone does **not** push everyone already on the board as deals. The contact must actually be linked (came from LeadConnector or contact sync).

## 💡 Typical uses

| Use | How |
|-----|-----|
| Sales board | New Lead → Contacted → Proposal Sent → Closed — drag as you go |
| Same board in LeadConnector | Create here, choose location, save — or **Sync Pipeline** if it already exists there |
| Local-only process | **Don’t sync to GHL** |
| Call a stage | **Dial** on the column |
| Text from the board | **Message** on the card → Conversations |
